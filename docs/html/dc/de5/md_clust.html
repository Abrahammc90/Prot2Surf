clust.f90

Description

clust performs hierarchical clustering on encounter data using mean linkage.

The input passed with -input must be a single-line 1D array generated by make_data.

The program reads encounter complexes, runs clustering, and writes output files using the provided output name.

Parser description

Required Arguments

  • -complexes <file>
  • -input <file>
  • -output_name <name>

Optional arguments

  • -nb_encounters <N> (default: all)
  • -help

Modules Used

  • mod_array
  • mod_clust_algorithm
  • read_input

Main Routines Called

  • read_assoc (from read_input)
  • read_array (from mod_array)
  • linkage_clustering (from mod_clust_algorithm)
  • print_help (internal)

Notes

  • Clustering runs on CPU for array inputs.
  • If -nb_encounters is omitted, all encounters in the complexes file are used.

Usage Example

./clust -complexes assoc_complexes -input array_z.txt -nb_encounters 5000 -output_name Cu_z
