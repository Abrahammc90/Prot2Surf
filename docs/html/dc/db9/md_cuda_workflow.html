Clustering program
CUDA Workflow for Hierarchical Clustering

Overview

This project supports optional CUDA acceleration for hierarchical clustering.

Scope constraint: CUDA is used only for the matrix-distance clustering path (2D N x N matrix). Array-based (1D) clustering remains CPU-only.

Components

  • mod_cuda.f90: Fortran interface (ISO C binding) to CUDA code
  • cuda_kernels.cu: CUDA wrapper and kernels
  • mod_clust_algorithm.f90: selects CPU or CUDA matrix clustering path
  • clust.f90 / clust_all.f90: expose -cuda CLI option

Execution Flow

  1. Main program parses arguments and identifies matrix clustering path.
  2. mod_clust_algorithm calls cuda_matrix_clustering when -cuda is enabled.
  3. mod_cuda bridges Fortran data to C/CUDA wrapper (cuda_matrix_clustering_c).
  4. CUDA code allocates device memory, runs clustering kernels, and updates cluster state.
  5. Results are copied back to host and standard output routines continue in Fortran.

Key Routines

  • cuda_matrix_clustering (mod_cuda.f90): Fortran entry point
  • cuda_matrix_clustering_c (cuda_kernels.cu): C/CUDA wrapper
  • device/global kernels in cuda_kernels.cu: core GPU clustering operations

Usage

./clust -complexes assoc_complexes -input matrix_z.txt -output_name Cu_z -linkage mean -cuda

If input is a 1D array, the computation stays on CPU even if -cuda is provided.

Notes

  • Data layout is Fortran-compatible (column-major assumptions are preserved).
  • GPU acceleration targets clustering compute, not full pipeline I/O/preprocessing.
  • A CUDA-capable GPU, runtime, and compatible toolchain are required.
