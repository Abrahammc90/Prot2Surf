Calculate maximum batch size for matrix processing.

Given available memory and memory to leave free (in percentage), calculates the maximum number of encounters that can be processed.

Formula: usable_memory = available_memory * (1 - reserve_percent/100) bytes_per_encounter = nb_total_encounters * 8 + other_overhead max_batch = usable_memory / bytes_per_encounter

Parameters
[in]available_memoryAvailable system RAM in bytes
[in]nb_total_encountersTotal number of encounters to process
[in]reserve_percentPercentage of memory to keep free (default 20)
Returns
maximum batch size (number of encounters per batch)
