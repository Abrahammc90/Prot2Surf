Detailed Description

Build matrices/arrays and perform clustering in memory (no disk I/O). Usage: ./clust_all -help.

This driver combines two traditionally separate phases: (1) metric generation from encounter transforms and atom selections, and (2) hierarchical clustering on the generated metric.

Compared with split workflows (make_data then clust), this program keeps intermediate numeric data in memory to reduce temporary files and simplify large-batch runs.
