Detailed Description

Threshold-based encounter selection from precomputed arrays.

threshold.f90 - Filter encounters using an input array generated by make_data.

Usage: ./threshold -help

Reads a precomputed per-encounter array and the matching complexes file, applies a cutoff, and writes filtered array values and filtered complexes.
