Complete GPU clustering pipeline with single CPU-GPU transfer.

This function takes a distance matrix computed on CPU and performs ALL subsequent operations on GPU:

  1. Transfer matrix to GPU (once)
  2. Compute clustering on GPU
  3. Find representative values on GPU
  4. Compute cluster statistics on GPU
  5. Sort clusters on GPU (if requested)
  6. Transfer results back (once)
Parameters
[in]matrixDistance matrix (n x n)
