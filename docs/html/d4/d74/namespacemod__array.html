Build matrix of angular differences between encounters.

Computes the angle (2D or 3D) for each encounter and fills the pairwise absolute difference matrix.

Parameters
[out]matrixOutput (n,n) matrix of pairwise angular differences
[out]arrayOutput (n) array with per-encounter angles
[in]nNumber of encounters
[in]nb_atomsNumber of atoms in solute 2 to transform
[in]xc1,xc2Solute centers used for translation transformations
[in]trans_vectorTransform translation vectors (n,3)
[in]rot1,rot2Transform rotation arrays (n,3)
[in]point1aFirst point defining reference vector
[in]point1bSecond point defining reference vector
[in]point2aFirst point of vector to be transformed
[in]point2bSecond point of vector to be transformed
[in]dimensionsDimensionality of angle calculation (2 or 3)

Build matrix from minimum inter-atomic distances between two solutes.

For each encounter, the second solute is transformed and the minimum distance to solute1_crds is computed; pairwise absolute differences of these minima populate matrix.

Parameters
[out]matrixOutput (n,n) matrix of pairwise values
[out]arrayOutput (n) array with per-encounter minimum distances
[in]nNumber of encounters
[in]nb_atomsNumber of atoms in solute 2 to transform
[in]xc1,xc2Solute centers used for translation transformations
[in]trans_vectorTransform translation vectors (n,3)
[in]rot1,rot2Transform rotation arrays (n,3)
[in]solute1_crdsCoordinates of first solute atoms
[in]solute2_crdsCoordinates of second solute atoms
