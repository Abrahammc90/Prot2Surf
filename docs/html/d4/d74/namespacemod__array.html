Compute angle between two vectors (defined by atom groups) per encounter and sort.

Computes the angle between two vectors (defined by atom groups) for each encounter. The resulting array is sorted from minimum to maximum value.

Parameters
[in,out]complexesAssociation object reordered consistently with sorted outputs
[out]array_sortedOutput array of length n with angles (sorted)
[in]nNumber of encounters
[in]nb_atomsNumber of atoms used for transformation
[in]xc1,xc2Solute centers used for translation transformations
[in]trans_vectorTranslation vectors for each encounter (n, 3)
[in]rot1,rot2Rotation vectors for each encounter (n, 3)
[in]point1aFirst point defining reference vector
[in]point1bSecond point defining reference vector
[in]point2aFirst point of vector to be transformed
[in]point2bSecond point of vector to be transformed
[in]dimensionsUse 2 or 3 to select projection

For each encounter, the second solute is transformed and the minimum distance to solute1_crds is computed and stored in the output array. The resulting array is sorted from minimum to maximum value.
