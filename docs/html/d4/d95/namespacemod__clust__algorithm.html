Perform hierarchical clustering on a distance array.

This routine performs hierarchical clustering using mean linkage on the input array (shape (n)) of sorted per-encounter values. The routine mutates array during merging and terminates merging when clusters are farther apart than an internally computed threshold. Results are written to files named using output_name and complexes information is optionally recorded via the complexes structure.

Parameters
[in,out]arrayArray of per-encounter values (n) This array is updated during clustering
[in]nNumber of elements / encounters
[in]output_nameBase name for output files
[in]complexesStructure containing complex text lines/headers
