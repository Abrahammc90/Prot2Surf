Compute angle between two vectors (defined by atom groups) per encounter.

Transforms the pair of points from solute2 for each encounter and computes the angle between the vector defined by point1b-point1a and the vector defined by the transformed point2b-point2a.

Parameters
[out]arrayOutput array of length n with angles in degrees
[in]nNumber of encounters
[in]nb_atomsNumber of atoms used for transformation
[in]xc1,xc2Centers used for transform
[in]trans_vectorTranslation vectors for each encounter (n, 3)
[in]rot1,rot2Rotation vectors for each encounter (n, 3)
[in]point1aFirst point defining reference vector
[in]point1bSecond point defining reference vector
[in]point2aFirst point of vector to be transformed
[in]point2bSecond point of vector to be transformed
[in]dimensionsUse 2 or 3 to select projection

Compute minimum inter-atomic distance between two solutes for each encounter.

For each encounter, the second solute is transformed and the minimum distance between any atom of solute1_crds and the transformed solute2_crds is computed and stored in array.

Parameters
[out]arrayOutput array of length n with minimum distances
[in]nNumber of encounters
[in]nb_atomsNumber of atoms in solute2_crds
[in]xc1,xc2Centers used for transform

[in]rot1,rot2Rotation vectors for each encounter (n, 3)
[in]solute1_crdsCoordinates of solute1 atoms
[in]solute2_crdsCoordinates of solute2 atoms

Compute the Z-coordinate (along transformed z-axis) for each encounter.

Recenters each encounter at xc2, applies rotation/translation using rot1/rot2 and trans_vector, and extracts the Z coordinate of the first atom in solute_crds for every encounter into array.

Parameters
[out]arrayOutput array of length n with z-coordinates
[in]nNumber of encounters
[in]nb_atomsNumber of atoms in solute_crds
[in]xc1,xc2Centers used for transform
[in]trans_vectorTranslation vectors for each encounter (n, 3)
[in]rot1,rot2Rotation vectors for each encounter (n, 3)
[in]solute_crdsCoordinates of solute atoms (nb_atoms, 3)
