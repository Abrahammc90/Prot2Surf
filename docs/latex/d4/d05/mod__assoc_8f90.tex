\doxysubsection{Detailed Description}
Association/complexes file data structures and parsing routines.

Association/complexes file utilities.

This module defines the {\ttfamily type\+\_\+assoc\+\_\+file} derived type and routines to allocate and populate it from an association/complexes text file. The {\ttfamily type\+\_\+assoc\+\_\+file} stores the raw file lines, header lines, per-\/encounter translation vectors and rotation vectors, and the two reference centers {\ttfamily xc1} and {\ttfamily xc2} extracted from the file header.
