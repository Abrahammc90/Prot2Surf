Perform hierarchical clustering on a distance array.

This routine performs hierarchical clustering using mean linkage on the input {\ttfamily array} (shape {\ttfamily (n)}) of sorted per-\/encounter values. The routine mutates {\ttfamily array} during merging and terminates merging when clusters are farther apart than an internally computed threshold. Results are written to files named using {\ttfamily output\+\_\+name} and complexes information is optionally recorded via the {\ttfamily complexes} structure.
