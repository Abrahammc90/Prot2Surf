Hierarchical clustering driver for encounter matrices/arrays. 

\mbox{\hyperlink{clust_8f90}{clust.\+f90}} -\/ Hierarchical clustering for encounter matrices.

Usage\+: ./clust -\/help

Reads a pairwise matrix (or array) and runs hierarchical clustering with user-\/specified linkage. Results written to output\+\_\+name files.
