{\footnotesize\ttfamily program main}



Command-\/line program to perform hierarchical clustering on encounter matrices. 

Reads a pairwise matrix (and optional array) and runs mean-\/linkage hierarchical clustering. Results are written to files using the {\ttfamily -\/output\+\_\+name} base name.
