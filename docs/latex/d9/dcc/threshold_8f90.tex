{\footnotesize\ttfamily program main}



Generate encounter selection based on threshold criteria. 

This executable computes thresholds (z\+\_\+coord, atoms\+\_\+dist, angles) across encounter transforms and writes selected encounter records to an output complexes file. See {\ttfamily print\+\_\+help} for usage examples.
