\doxysubsection{Detailed Description}
Threshold-\/based encounter selection utility. 

\mbox{\hyperlink{threshold_8f90}{threshold.\+f90}} -\/ Select encounters based on threshold criteria.

Usage\+: ./threshold -\/help

Computes thresholds (z\+\_\+coord, atoms\+\_\+dist, angles) and writes selected encounters to output. See print\+\_\+help for usage.
