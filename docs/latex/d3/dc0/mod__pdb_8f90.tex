\doxysubsection{Detailed Description}
P\+DB data structures and parsing/allocation routines. 

Module to define a pdb type and pdb reading routine for tools.

N\+O\+TE\+: This implementation is based on the S\+D\+A7 project\textquotesingle{}s {\ttfamily \mbox{\hyperlink{mod__pdb_8f90}{mod\+\_\+pdb.\+f90}}} (original author Neil Bruce). The present file has been modified and expanded for the clustering tools in this workspace. Notable enhancements include the addition of {\ttfamily count\+\_\+residues} and {\ttfamily count\+\_\+chains} functions and changes that allow creation of richer in-\/memory objects where residues contain their atoms and chains contain residues and atoms. These changes make it possible to build {\ttfamily type\+\_\+pdb\+\_\+file} instances with proper {\ttfamily residues} and {\ttfamily chains} substructures (each storing their atoms) rather than storing atoms in a single flat list only.
