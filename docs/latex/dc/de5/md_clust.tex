\hypertarget{md_clust_autotoc_md11}{}\doxysection{Description}\label{md_clust_autotoc_md11}
{\ttfamily clust} performs hierarchical clustering on encounter data using {\ttfamily min}, {\ttfamily max}, or {\ttfamily mean} linkage.

The input passed with {\ttfamily -\/input} is auto-\/detected\+:


\begin{DoxyItemize}
\item single line → treated as a 1D array
\item multiple lines → treated as a 2D distance matrix
\end{DoxyItemize}

The program reads encounter complexes, runs clustering, and writes output files using the provided output name.\hypertarget{md_clust_autotoc_md12}{}\doxysection{Parser description}\label{md_clust_autotoc_md12}
