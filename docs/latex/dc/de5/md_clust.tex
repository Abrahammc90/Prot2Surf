{\ttfamily clust} performs hierarchical clustering on encounter data using mean linkage.

The input passed with {\ttfamily -\/input} must be a single-\/line 1D array generated by {\ttfamily make\+\_\+data}.

The program reads encounter complexes, runs clustering, and writes output files using the provided output name.\hypertarget{md_clust_autotoc_md2}{}\doxysection{\texorpdfstring{Parser description}{Parser description}}\label{md_clust_autotoc_md2}
