G\+PU acceleration module using Open\+A\+CC for clustering algorithms. 

This module provides G\+P\+U-\/accelerated minimum distance finding using Open\+A\+CC directives. No external kernels required -\/ pure Fortran. Open\+A\+CC allows compilation with standard gfortran and is portable across different G\+PU architectures.

\begin{DoxyAuthor}{Author}
Abraham Muñiz-\/\+Chicharro Find minimum distance between clusters using G\+PU acceleration via Open\+A\+CC.
\end{DoxyAuthor}
Uses Open\+A\+CC parallel directives to accelerate the minimum distance search on G\+PU. Falls back to C\+PU if no G\+PU is available.

Completely pure Fortran -\/ no external kernels or C interoperability needed.
