{\bfseries{Array Parameter in Clustering\+:}}
\begin{DoxyItemize}
\item The {\ttfamily -\/array} option is {\bfseries{mandatory}} for all clustering methods {\bfseries{except R\+M\+SD}}
\item When using {\ttfamily -\/matrix\+\_\+type rmsd}, the array parameter is {\bfseries{optional}}
\item When an array is provided, complexes are sorted by the array values
\item If array is not provided for non-\/\+R\+M\+SD methods, an error is raised
\item Without an array, cluster averages and standard deviations are computed from the matrix
\end{DoxyItemize}
