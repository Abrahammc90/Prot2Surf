\hypertarget{md_threshold_autotoc_md38}{}\doxysection{Description}\label{md_threshold_autotoc_md38}
{\ttfamily threshold} selects encounter complexes based on a threshold criterion and writes both the computed value array and the filtered complexes.

Supported threshold modes include\+:


\begin{DoxyItemize}
\item {\ttfamily z\+\_\+coord}
\item {\ttfamily atoms\+\_\+dist}
\item {\ttfamily 2D\+\_\+angle}
\item {\ttfamily 3D\+\_\+angle}
\end{DoxyItemize}
