\doxysubsection{Detailed Description}
Unit tests for clustering algorithms in \mbox{\hyperlink{namespacemod__clust__algorithm}{mod\+\_\+clust\+\_\+algorithm}}. 

Tests include\+:
\begin{DoxyItemize}
\item Sort complexes functionality
\item Write cluster elements
\item Basic clustering threshold calculation
\item Minimum linkage clustering
\item Maximum linkage clustering
\item Mean linkage clustering
\end{DoxyItemize}

Note\+: Array parameter is mandatory for all clustering methods E\+X\+C\+E\+PT R\+M\+SD. For R\+M\+S\+D-\/based clustering, array is optional. When provided, array is used to compute cluster averages and standard deviations.
