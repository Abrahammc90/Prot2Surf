{\ttfamily analyze\+\_\+residues} evaluates residue proximity to a surface across encounter complexes.

For each residue in {\ttfamily pdb2}, it computes a center-\/of-\/geometry, applies encounter transformations, and records encounters where the transformed residue position is below a distance threshold.\hypertarget{md_analyze_residues_autotoc_md2}{}\doxysection{Parser description}\label{md_analyze_residues_autotoc_md2}
