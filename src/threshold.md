# threshold.f90

## Description

`threshold` filters encounters using a precomputed array generated by `make_data`.

It reads the array and complexes file, applies `-cutoff`, writes a filtered
array file, and writes filtered complexes.

## Parser description
# Required Arguments

- `-array_input <file>`
- `-array <file>`
- `-complexes <file>`
- `-complexes_output <file>`
- `-cutoff <value>`

# Optional arguments

- `-nb_encounters <N>`
- `-help`

## Modules Used

- `read_input`
- `mod_array` (`read_array`, `write_array`)
- `mod_threshold`

## Main Routines Called

- `read_assoc` (from `read_input`)
- `read_array`, `write_array` (from `mod_array`)
- `sort_array` (from `mod_threshold`)
- `write_cutoff_complexes` (internal)
- `print_help` (internal)

## Usage Example

```bash
./threshold -array_input array_z.txt -complexes assoc_complexes -array threshold_z_array.txt -complexes_output threshold_z.txt -cutoff 5.0
```
